## 🚀 How to Host This on GitHub Pages (Takes 30 Seconds!)

This repository contains a **single standalone file (`index.html`)** that has the complete website, React engine, icons, styling, campus data, chat system, and "Sold Out" management bundled together with zero external build requirements.

### Step 1: Upload to GitHub
1. Create a new repository on [GitHub](https://github.com/new) (e.g., `cgc-campus-olx`).
2. Click **"uploading an existing file"**.
3. Drag and drop `index.html` and this `README.md` into the browser window.
4. Click **"Commit changes"**.

### Step 2: Turn on Free Live Website (GitHub Pages)
1. In your GitHub repository, click on **Settings** (top right tab).
2. On the left sidebar, click on **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Within 1 minute, GitHub will give you a live URL:
   `https://<your-username>.github.io/<repo-name>/`

## 🌟 Features Included
- 📚 **Campus Exchange Items**: Books, Notes, Drafters, Cycles, Electronics, Hostel gear.
- 🏷️ **Sold Out Badge & Toggle**: Mark items as "Sold Out" once an exchange is completed.
- 💬 **Live In-App Chat Messenger**: Built-in chat between buyers and sellers with quick icebreaker prompts.
- 📱 **WhatsApp Shortcut**: Direct button to message the student seller on WhatsApp.
- 🛡️ **Campus Safety Guide**: Tips for safe, in-person daylight meetups at the Central Canteen or Library.
- ⚡ **Student Wanted Board**: Notice board where students can request urgent items before exams.
